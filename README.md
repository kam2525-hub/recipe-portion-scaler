# レシピ分量自動換算機

作りたい人数や余った食材の半端なグラム数に合わせて、調味料を含むレシピ全体の分量を瞬時に再計算するツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス）。
2. 画面の指示に従って操作します。
